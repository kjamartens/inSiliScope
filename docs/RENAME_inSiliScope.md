# Rename: insilicell / inSiliCellScope -> inSiliScope

Instructions for the agent (or person) doing the rename. Written 2026-09-25, after M4's CI block
(`tools/make_cellfield_block.mjs`) and before the webSMLM side of M4.

## 0. Do it in place, not in a new repo

A new repo loses the issue/PR history, the Actions settings and the old-URL redirects, and gains
nothing. Instead:

1. **Owner renames the GitHub repo** (an agent cannot): github.com/kjamartens/insilicell ->
   Settings -> General -> Repository name -> `inSiliScope`. GitHub redirects the old URL (web, git
   clone/push, API) until a new repo takes the old name. Locally: `git remote set-url origin
   https://github.com/kjamartens/inSiliScope.git` (optional, the redirect works). In Claude Code on
   the web, re-select the repo for new sessions; running sessions keep the old name.
2. **An agent then does the internal rename** below as one commit on a branch in the renamed repo.

Do it **before** the webSMLM side of M4: the block's markers and header carry the name, and
webSMLM's `tools/sync_cellfield.mjs` will match on them.

hardware configurations must be re-made (as with the SMLMDemoCam rename); `bin/windows-x64/` must be

## 2. Steps

1. Branch from the default branch. Inventory: `git grep -Ii -e insilicell -e 'in silico cell'`
   (~630 hits in ~45 files as of 2026-09-25, plus 40 paths with `insilicell`/`inSiliCellScope` in them;
   `git ls-files | grep -i insilicell`).
2. **Paths first, with `git mv`** (keeps history): `adapter/inSiliCellScope/` -> `adapter/inSiliScope/`,
   the `InSiliCellScope*` sources, `inSiliCellScope.sln/.vcxproj/.vcxproj.filters/.rc`,
   `core/include/insilicell/`, `cli/insilicell_cli.cpp`, `tools/test_insilicellscope.py`,
   `web/insilicell_module.js`. Delete `bin/windows-x64/mmgr_dal_inSiliCellScope.dll` (+ `BUILD_INFO.txt`
   refers to it; regenerated by CI).
3. **Content**, case-sensitive and longest-first so `inSiliCellScope` is not half-replaced by the
   `insilicell` rule: `InSiliCellScope` -> `InSiliScope`, `inSiliCellScope` -> `inSiliScope`,
   `insilicellscope` -> `insiliscope`, `INSILICELL` -> `INSILISCOPE`, `Insilicell` -> `Insiliscope`,
   `insilicell` -> `insiliscope`. Then review every hit by hand in:
   - `.vcxproj`/`.filters`/`.sln` (paths, `ProjectName`, `TargetName`; keep the project GUID),
   - `inSiliScope.rc` (version-info strings),
   - the MM module (`InSiliScopeModule.cpp`: module/device registration strings),
   - `.github/workflows/*.yml` (DLL path, artifact names, `Collect DLL` step),
   - `web/index.html` (`createInsiliscope`, module file name), `tests/parity/*.mjs`,
   - `web/tools/package-lock.json` (package `name` only),
   - prose in `README.md`, `CLAUDE.md`, `PLAN.md`, `spec/*.md`, `docs/*.md` (keep the historical notes, see 1).
   **Never touch** `spec/golden/*` (frozen JS reference outputs), `core/src/jsmath_fdlibm.cpp`
   (generated), or anything under `third_party/mmCoreAndDevices` (submodule).
4. Rebuild generated files with their tools, never by hand: `node tools/embed_web_module.mjs`
   (new `web/insiliscope_module.js`), `node tools/make_cellfield_block.mjs`.
5. Verify (all must pass; outputs must not change -- a rename is not a behaviour change):
   - native: `cmake -S . -B build/native -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build/native && ctest --test-dir build/native`
   - WASM: `source ~/emsdk/emsdk_env.sh && cmake --preset wasm && cmake --build --preset wasm && ctest --test-dir build/wasm`,
     `node tools/embed_web_module.mjs --check`, `node tests/block/check_cellfield_block.mjs`
   - the block's `sha256(module)` must be unchanged (its target has no export name), and
     `tests/block/check_cellfield_block.mjs` prints the same site counts before and after.
   - `node tests/parity/run.mjs`; `node web/tools/check_cellfield_microtubules.mjs`
   - adapter: `tools/build_adapter_linux.sh` + `tools/test_cellfield_stage.py` (Linux);
     on Windows MSBuild `adapter/inSiliScope/inSiliScope.sln` and `python tools/adapter_pixel_hash.py <dll dir>`
     before/after: identical hashes (or run CI with `publish_dll`).
   - `git grep -Ii insilicell` returns only the deliberate historical notes.
6. PLAN.md: add a ticked item "Rename (user request): insilicell/inSiliCellScope -> inSiliScope" with the
   mapping and the "re-make MM hardware configs" note, like the existing SMLMDemoCam rename item.
   CLAUDE.md: update names and the header line.
7. Commit (one commit, `Co-Authored-By` line), push, then run CI (`publish_dll`) so
   `bin/windows-x64/mmgr_dal_inSiliScope.dll` exists again.
