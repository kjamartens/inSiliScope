Cell field — seed→coordinate mock

Chunk-hashed, address-based placement (pcg4d, ported from webSMLM / demoCam_SMLM_MM's CounterRng). Every cell/nucleus is a pure function of (seed, chunk coords) — nothing is generated ahead of time, so you can pan infinitely and re-enter the same spot deterministically. Not wired into webSMLM itself — standalone exploration only.

Drag to pan, wheel to zoom. Panning is exactly the drift/ stage-motion case for demoCam_SMLM_MM: the field doesn't move, the viewport (camera FOV) does, and the same world coordinate always re-derives the same structure. When packing is on, overlap is measured against each cell's own true (elliptical + blobby) outline, not a circumscribed circle, so cells can nestle along their waists; overlapping cells push each other apart and, if rotation is allowed, also turn to reduce overlap (never shrink). A cell still stuck after relaxation is dropped entirely rather than resized — watch "removed" in the HUD — and the survivors get a short extra settle pass afterwards to close any gap the removal left open.
