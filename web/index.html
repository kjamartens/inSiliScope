Cell field viewer

The insiliscope world model (C++ core, compiled to WASM, run in Web Workers). Every cell, microtubule and dye is a pure function of (seed, address): pan anywhere and come back to the same structure. Cells are packed on fixed 8x8-chunk blocks, so what you see is what the Micro-Manager adapter images. The JS prototype this was ported from is in prototype/.

Drag to pan, wheel to zoom. Panning is exactly the stage-motion case for the inSiliScope adapter: the field does not move, the viewport (camera FOV) does, and the same world coordinate always re-derives the same structure. Packing moves and turns overlapping cells apart (never shrinks them) and drops a cell still stuck after relaxation. Dyes are the real labelled sites of the core (13_3 lattice, binder + linker), shown once zoomed in.
